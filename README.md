Resolución del ejercicio N°37 de la unidad 2 de programación 2.
Este programa implementa un sistema simulado para interactuar con diferentes redes de criptomonedas a través de una interfaz común, aplicando validaciones de formato de billetera específicas para cada tecnología blockchain y permitiendo procesar transacciones financieras de forma modular.

Clases utilizadas
RedBlockchain
RedBitcoin
RedEthereum
RedSolana
